# Asset Licenses

## First-Party Original Assets

All ship sprites, projectile art, effects, planets, UI chrome, and audio will be
original, model-generated assets created for Starfall. No content from the
original Star Control, Star Control II, or any descendant product is used.

| Asset | Type | License | Notes |
|-------|------|---------|-------|
| Ship SVG art | Original vector art | First-party, original work | One SVG per ship, authored by model |
| Projectile SVG art | Original vector art | First-party, original work | Per-weapon projectile designs |
| Effect SVG art | Original vector art | First-party, original work | Explosions, shields, special ability visuals |
| Planet SVG art | Original vector art | First-party, original work | Planet bodies for melee arenas |
| UI chrome SVG | Original vector art | First-party, original work | HUD, menus, ship select, star map chrome |
| Starfield SVG | Original vector art | First-party, original work | Parallax starfield layers |
| Audio: weapon fires | Original synthesized audio | First-party, original work | Generated programmatically |
| Audio: impacts/explosions | Original synthesized audio | First-party, original work | Generated programmatically |
| Audio: thrusters | Original synthesized audio | First-party, original work | Generated programmatically |
| Audio: UI sounds | Original synthesized audio | First-party, original work | Generated programmatically |
| Audio: menu theme | Original composed music | First-party, original work | Composed programmatically |
| Audio: combat theme | Original composed music | First-party, original work | Composed programmatically |

## Research Notes on Source Licensing

- Star Control II / The Ur-Quan Masters open-source project distributes its
  _code_ under a permissive license but its _content_ (art, music, voice) under
  a non-commercial license. Verified from the Ur-Quan Masters project page.
  We use zero sourced assets from this project.
- The Star Control trademark is contested between multiple parties. We do not
  use the "Star Control" name in our game title, species names, or marketing.
  Our game is titled "Starfall."
